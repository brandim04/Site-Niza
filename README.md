# 🥖 Niza Alimentos — Landing Page

Este projeto consiste no desenvolvimento de uma landing page para a Niza Alimentos, uma padaria artesanal e fábrica de pães localizada em Timon - MA.

O objetivo do site é apresentar a empresa, divulgar seus produtos e facilitar o contato com clientes, permitindo o envio de encomendas de forma simples e rápida.

---

## 🚀 Sobre o projeto

A página foi desenvolvida com foco em:

- Apresentação da empresa
- Divulgação dos produtos e serviços
- Facilidade de contato via WhatsApp
- Experiência do usuário (UX)
- Design moderno e responsivo

O site possui seções como:

- Banner principal (hero)
- Sobre a empresa
- Fábrica (atacado)
- Encomendas com formulário
- Contato
- Destaque para nova unidade

---

## 💻 Tecnologias utilizadas

- HTML
- CSS
- JavaScript

---

## 🎨 Destaques técnicos

- Uso de variáveis CSS (`:root`)
- Animações com `@keyframes`
- Layout com Flexbox e Grid
- Responsividade com `@media`
- Interatividade com JavaScript
- Formulário integrado ao WhatsApp (sem backend)
